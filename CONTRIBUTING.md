# Contributing to LibreAudio PRO

Thank you for your interest in contributing to LibreAudio PRO! This document provides guidelines for contributing to the project.

## Code of Conduct

Please be respectful and considerate in all interactions with the community.

## How to Contribute

### Reporting Bugs

- Check if the bug has already been reported in the Issues section
- Use a clear and descriptive title
- Provide detailed steps to reproduce the bug
- Include screenshots if applicable
- Specify your environment (OS, Docker version, etc.)

### Suggesting Features

- Check if the feature has already been suggested
- Provide a clear description of the feature
- Explain why this feature would be useful
- Consider if the feature aligns with the project's goals

### Pull Requests

1. Fork the repository
2. Create a new branch from `main`
3. Make your changes
4. Write clear commit messages
5. Test your changes thoroughly
6. Update documentation if needed
7. Submit a pull request

### Coding Standards

- Follow CakePHP coding standards
- Write meaningful variable and function names
- Add comments for complex logic
- Keep functions small and focused
- Write unit tests for new features

### Testing

Before submitting a pull request:
- Test your changes locally
- Ensure all existing tests pass
- Add tests for new functionality
- Test in Docker environment

## Development Setup

See the main README.md for setup instructions.

## Questions?

Feel free to open an issue for questions or clarifications.

Thank you for contributing!
