# LibreAudio PRO - PWA

Progressive Web App de LibreAudio PRO optimizada para GitHub Pages.

## Demo

👉 [Ver demo en vivo](https://luisitoys12.github.io/LibreAudio-PRO/)

## Características

- 🎵 Directorio de radios y podcasts
- 💾 Almacenamiento local (localStorage)
- 📱 Instalable como app nativa
- 🔍 Búsqueda en tiempo real
- 📤 Importar/Exportar datos
- ⚡ Funciona offline

## Instalación

### Android/iOS
1. Abre la URL en tu navegador
2. "Agregar a pantalla de inicio"

### Desktop
1. Abre la URL en Chrome/Edge
2. Clic en el ícono de instalación (+)

## Desarrollo Local

```bash
cd docs
python3 -m http.server 8000
```

Abre http://localhost:8000

## Estructura

```
docs/
├── index.html       # App principal
├── manifest.json    # PWA manifest
├── sw.js           # Service Worker
└── icons/          # Íconos de la app
```
